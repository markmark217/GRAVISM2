# Development of an Interactive Computational Simulation of Gravitational Lensing Using Python for Physics Education

## 1. Project Identity

**Project Title:**

Development of an Interactive Computational Simulation of Gravitational Lensing Using Python for Physics Education

**Project Description:**

An interactive computational physics application developed using Python to simulate, visualize, and analyze gravitational lensing phenomena. The platform allows students to investigate how massive astronomical objects bend the path of light through gravitational fields.

The application combines numerical methods, mathematical modeling, astronomical data, and scientific visualization to provide an interactive learning and research environment for undergraduate physics students.

**Primary Objectives:**
- Develop a computational simulation of gravitational lensing using Python.
- Visualize the deflection of light around massive astronomical objects.
- Demonstrate Einstein rings, multiple images, and gravitational magnification.
- Allow users to manipulate physical parameters and observe their effects.
- Integrate mathematical calculations with interactive scientific visualization.
- Support physics education through computational experiments.

## 7. Writing and Communication Style

The platform should maintain a professional, scientific, and educational tone.

**Tone:**
- Professional
- Scientific
- Informative
- Approachable
- Educational
- Technically accurate

**Writing Guidelines:**
- Use accurate physics terminology.
- Explain complex scientific concepts clearly.
- Avoid unnecessary technical jargon.
- Include equations when they help explain physical processes.
- Always identify units in numerical results.
- Clearly distinguish theoretical predictions from numerical simulations and observational data.

**Example:**

Instead of:

"The light bends because of the black hole."

Use:

"The gravitational field of a massive object changes the propagation path of light, producing gravitational deflection. This phenomenon is known as gravitational lensing."
